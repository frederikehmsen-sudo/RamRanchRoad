# RamRanchRoad
## Lighthouse Analyse

Som man kan se på billedet under, er vores program godt kørende, tilgængeligheden er godt, og vores website følger de forskellige sikkerheds protokoller inden for development standards. Grunden til at SEO er lidt værre, er på grund af at lighthouse ikke forstod nogle af vores syntaxes, og fordi at vores side ikke har meta description.

## Unit Testing

I dette project har vi brugt unit testing til at teste vores kode, for at se om det fungerer ordentligt. Vi bruger metoden "Test Last" hvor vi laver vores klasse først, med alt indhold, og derefter tester vi med en test klasse, hvor vi bruger en bestemt database fixture, så den ikke kan tage direkte fra databasen.

![img_2.png](img_2.png)

Vi har valgt at teste vores OrderService klasse, hvor vi f.eks. tester om der bliver fjernet noget fra listing stocken, når der bliver købt derfra.
